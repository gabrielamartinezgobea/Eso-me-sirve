
# ESO me sirve - Tres Cantos

## Descripción
Proyecto web educativo para facilitar la compra, venta y donación de material escolar usado en Tres Cantos y a la vez agruparse para un fin común relacionado a la vida educativa.

## Objetivo
Ayudar a las familias a reutilizar libros, mochilas, uniformes y otros materiales escolares.

## Páginas
- inicio.html: página principal.
- login.html: acceso simulado.
- formulario.html: registro simulado.
- acceso.html: elección de actividad.
- categorias.html: categorías de productos.
- catalogo.html: catálogo de productos.
- detalle.html: información de un producto.
- carrito.html: carrito de compra simulado.

## Tecnologías
- HTML
- CSS

## Limitaciones
Es un prototipo educativo. No guarda cuentas, no realiza pagos reales y no tiene una base de datos.

## Publicación
La web se publicará mediante GitHub Pages.
